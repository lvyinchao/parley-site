如何获取 API Key？

  1. 打开 qianwenai.com，注册并登录千问AI平台。
  2. 进入控制台的 API Key 页面，点击「创建 API Key」。
  3. 填写描述后点击「生成 API Key」，立即复制保存（只显示一次）。
  4. 在 SyncTalk 的「设置」中，服务平台选择「千问AI平台」，粘贴 Key，点击「测试连接」确认连接与认证，然后点击「完成」保存设置。开始翻译后再验证实际效果。

常见问题

测试连接显示 401 / 403：Key 填写错误或已删除，或服务平台选择不正确。

说话时音量条不动：点击麦克风按钮右侧的音频按钮，换一个输入设备再试。

对面的人听不到译文：在音频设备中打开「扬声器外放」。

Plans, allowance, and accounts

Versions with commerce enabled offer one five-minute managed trial per account, a lifetime BYOK purchase, and an auto-renewing monthly plan with 300 minutes per billing period. Available plans and local prices are shown in the app.

Connected time, including silence, uses managed minutes. Stop translating when idle. Monthly minutes do not roll over; service stops when exhausted, with no automatic overage charges. BYOK provider fees are separate.

Use Translation Plans & Purchases to restore purchases, redeem Apple offer codes, or delete your cloud account. Deletion does not cancel a subscription: manage it in Apple subscription settings. The privacy policy explains retained anti-abuse markers. Apple's Standard EULA applies.

How do I get an API key?

  1. Open qianwenai.com, then sign up and log in to the Qianwen AI Platform.
  2. Go to the API Key page in the console and click “Create API Key”.
  3. Enter a description, click “Generate API Key”, then copy and save it right away (it's shown only once).
  4. In SyncTalk's Settings, set Service Platform to “Qianwen AI Platform”, paste the key, tap “Test Connection” to check the connection and authentication, then tap “Done” to save. Start translating to verify the results.

FAQ

Test Connection shows 401 / 403: the key is wrong or deleted, or the service platform doesn't match.

The level bars don't move when I speak: tap the audio button next to the mic button and pick another input device.

The other person can't hear the translation: turn on Loudspeaker in Audio Devices.
